# 案例复盘口径

| 词 | 在本书复盘时的处理 |
|---|---|
| 利润分成 | 与约定项目利润挂钩的对价，记录分母、比例和是否签订。 |
| 担保 | 记录提供者、受益人、触发条件和上限；经手资金的主体未必承诺担保。 |
| 转仓 | 旧到期头寸与新到期头寸分开记录。延期可改变时间分布，原头寸盈亏及新的资金需要另核。 |
| 名义数量 | 手数乘合约单位所得标的量；期权的实际义务取决于条款及行权。 |
| 可交割量 | 对特定合约、地点、主体和截止日核实后，可以交付的数量。 |
| 保证金 | 核查现金的缴付时点。账面现货能否及时变现另列。 |
| 同源转述 | 多条报道引用同一份公告或采访。记录传播节点，同时保留一个原始来源。 |
| 观察人 | 复盘所站的位置，如刘春云。作者向读者披露的信息可能尚未到达此人。 |
